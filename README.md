# HR_Analytics
HR Analytics project analyzing employee demographics, hiring trends, gender distribution, geographic distribution, and department-wise workforce data using data visualization.
## Project Overview

This project analyzes Human Resources data to understand workforce patterns, employee demographics, hiring trends, geographic distribution, and department-wise employee distribution.

The project uses data visualization to present important HR insights and support data-driven workforce analysis.

## Project Objectives

The main objectives of this project are:

- Analyze hiring trends over time
- Understand employee distribution by department
- Analyze employee distribution across states
- Examine gender distribution
- Analyze employee demographics
- Identify important workforce patterns

## Analysis Performed

The project includes analysis of:

### Hiring Rate by Year

Analyzed employee hiring patterns over different years to understand changes in recruitment activity.

### Employees by Department

Analyzed the distribution of employees across different departments to understand workforce composition.

### Employees by State

Analyzed the geographic distribution of employees across different states.

### Gender Distribution

Analyzed the gender distribution of employees to understand workforce composition.

### Employees by Race

Analyzed employee distribution across different racial categories to understand workforce demographics.

## Key Visualizations
